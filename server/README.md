# Копатель Онлайн 2012: локальний сервер

Власний сервер для браузерної версії гри 2012 року (Unity 3.5, Unity Web Player).
Клієнт узято з фанатського сайту kopatel-online.ru і пропатчено, щоб він працював із цим сервером.

## Що потрібно

- Windows з Python 3.10 або новішим (`python --version`).
- Firefox 51 (32-біт) з вимкненим автооновленням і Unity Web Player.

## Запуск

1. Двічі клацніть `run_server.bat` (або виконайте `python run_server.py`).
   Коли Windows спитає про брандмауер, дозвольте доступ для Python.
2. У Firefox 51 відкрийте `http://127.0.0.1:8080/`.
3. Натисніть «Регистрация» й створіть акаунт. Пошта та пароль можуть бути будь-якими,
   бо вони зберігаються тільки на цьому комп'ютері. Потім увійдіть і виберіть нік.
4. «Мои карты» → «Карта 1» → «Создать», щоб створити карту. Сама вона не зберігається:
   у грі натисніть Esc → «Мои карты» → слот → кнопку збереження. Наступного разу збережена
   карта відкриється з того ж слота.

Новий гравець отримує 500 кристалів і 50 000 монет (параметри `--start-crystals`, `--start-coins`).
Справжньої оплати немає: «покупка» кристалів у грі видає їх безкоштовно.

## Порти

| Порт | Для чого |
|---|---|
| 8080 | сторінка гри, клієнт і API (`--http-port`) |
| 4530, 4531 | Photon: master і game server |
| 843 | socket policy, без неї Unity Web Player не відкриває з'єднання |

Порти 4530, 4531 і 843 зашиті в клієнт, їх не можна змінити без перезбирання.

**Гра з друзями в локальній мережі:** вони відкривають `http://<ваш IP>:8080/` (адресу сервер
показує під час запуску). **Через інтернет:** перекиньте на роутері TCP-порти 8080, 4530, 4531 і 843
на цей комп'ютер і запускайте `python run_server.py --public-host <ваш зовнішній IP>`.

## Що працює, а що ні

- Працює: реєстрація й вхід, профіль, нік, скіни, слоти карт, створення, збереження й завантаження
  карт, перегенерація слота (стара карта йде в `data/backups`), публікація карт, топи, пошук,
  коментарі, оцінки, магазин за кристали й монети, переказ монет.
- Сервер Photon (лобі, кімнати, події, властивості, кеш подій) повністю реалізований і протестований.
- Фанати вирізали з клієнта 2012 року код кімнат, появи гравця, камери та синхронізації руху.
  Його відновлено за клієнтом 2014 року (`patcher/Fixes/KopFix.cs`): гравець створює кімнату на
  сервері, а друзі можуть зайти до нього через список серверів. У реальній грі вдвох це ще не
  перевірено. Якщо сервер недоступний, гра запускається сама (офлайн-режим PUN).
- Звуки: оригінального `Sounds3.unity3d` ніде не лишилося, тому ті самі кліпи (з тими самими
  назвами) взято з новішої збірки гри `diggerworld.zip` (фанатський лаунчер на Яндекс.Диску) і
  покладено в `www/sounds/` як WAV. Клієнт вантажить їх по одному. Немає лише `TorchLoop`, замість
  нього тиша. Перегенерувати: `python -I tools/extract_sounds.py diggerworld.zip`
  (потрібен `pip install UnityPy`). Окремо лежать `Explode_1..4.wav`, вибух динаміту й авіабомби:
  класичний звук TNT із Minecraft (`random/explode1..4.ogg` з індексу ассетів 1.20, переведені
  у WAV через `ffmpeg -i explodeN.ogg -acodec pcm_s16le Explode_N.wav`).
- Зброя на картах для будування: G дає зброю, як у бою (див. нижче). У грі ще не перевірено.
- Голосовий чат працює на всіх картах. Утримуй P й говори, O вмикає або вимикає передачу без
  утримання. Під час першого натискання гра питає дозвіл на мікрофон. Звук іде через Photon як RPC
  `SendAudio` (Speex, ~150 байт на 40 мс). Перевірити його можна ботом:
  `python tests/voice_check.py --wait 300 --echo`. Бот заходить у кімнату, рахує пакети голосу й
  повертає їх тому, хто говорив. Приватні кімнати зі списку приховані, тож для бота заходь
  на карту через «Быстрая игра» або передай йому назву кімнати через `--room`.

## Файли

- `run_server.py`, `kopserver/`: сервер (HTTP API, емулятор Photon, база).
- `www/`: сторінка гри та пропатчений клієнт `Digger2012.unity3d`. Сервер віддає їх і звуки з ETag
  та `Cache-Control: no-cache`. Браузер тримає копію, але щоразу питає, чи вона ще свіжа. Тому
  перезібраний клієнт гравці отримують при наступному запуску, а незмінений не качається вдруге.
- `data/keys.json`: ключі, вшиті в клієнт. Наступні збирання беруть RSA-ключ звідси, тож
  перезібраний клієнт працює з уже запущеним сервером.
- `data/db.json`, `data/worlds/`, `data/backups/`: акаунти та карти; з'являються після першого запуску.
- `tools/build_client.py`: перезбирає клієнт і ключі (потрібен .NET SDK):
  `python -I tools/build_client.py`.
- `patcher/`: патчер клієнта на C# (Mono.Cecil).
- `tests/smoke_test.py`: перевірка запущеного сервера: `python tests/smoke_test.py`.
  Вона створює тестові акаунти, тож для неї краще запускати сервер з окремою папкою `--data`.

## Що змінено в клієнті

- Усі адреси kopatel-online.ru беруться з адреси, з якої завантажено гру.
- Photon підключається по TCP до `<той самий хост>:4530`, а не до мертвого додатка в Photon Cloud.
- Відновлено вирізаний фанатами код: створення кімнати й вхід до неї (`Level.Start`,
  `WorldGameObject.StartServer`/`OnCreatedRoom`), появу гравця через `PhotonNetwork.Instantiate`,
  налаштування камери, межі карти (`LateUpdate`), інтерполяцію руху інших гравців.
- Повернуто 22 перевірки `photonView.isMine`, які фанати замінили константами.
- Виправлено `WorldGameObject.Update`: фанатська правка робила його некоректним IL, і Unity його
  відкидав (не працювали меню, драбини, повернення гравця, що впав за карту).
- `ResourceLoader.Start` (фанати його спорожнили) знову вантажить звуки, тепер із `www/sounds/`.
- Підпис покупок за монети використовує новий RSA-ключ із `data/keys.json`.
- F12 (`MainMenu.toggleFullScreen`): якщо сторінка відкрита в лаунчері, гра просить у неї повний
  екран Firefox, з якого Esc не виходить. Про лаунчер сторінка повідомляє у відповідь на `KopHello`
  з `App.Start`. Поза лаунчером F12, як і раніше, вмикає повний екран Unity.
- `App.Start` ставить `Application.targetFrameRate = 120`. Без цього Web Player планує кадр на
  ~16,7 мс, Windows округлює це до двох тіків таймера (2 × 15,6 мс), і гра впирається в 32 FPS.
  Тепер стеля ~64 FPS: один тік. Вище не дає точність таймера процесу плагіна, а змінити її з
  пісочниці Web Player не можна. `App.Update` раз на 10 с пише в лог `Kop fps: …` з розміром кадру.
- Голосовий чат: P обробляла лише бойова частина `CameraController.UpdateWeapon`, тепер є й поза боєм
  (`CameraController.Kop_UpdateVoice`). `PlayerNetwork.SendAudio` більше не падає без `TeamBattle`
  і не пише в лог рядок щокадру. Надсилаються лише закодовані байти, а не весь буфер пулу (640 байт).
  У лозі `Kop voice: sent/received …` раз на 250 пакетів.
- `TNT`/`AviaBomb.Destruction` грають звук вибуху (`ResourceLoader.Kop_PlayExplosion`, на 10 м
  повна гучність).
- Зброя на картах для будування: G вмикає «режим зброї» (`Igor.enableGuns` тоді `true`). У ньому
  вікно вибору зброї, 1–4, R, приціл і шкода гравцям працюють, як у бою, а набої поповнюються після
  кожного G. Ще раз G повертає лопату. Код, що спирався на `TeamBattle` (його на таких картах немає),
  обходиться без нього: `Bullet.Update2`/`OnDestroy`, `CameraController.UpdateHud`. Здоров'я й
  набої показує `MainMenu.DrawSpecialBonus`. Гранати ламають блоки лише будівельникам (кулі вже
  перевіряє `World.Dig2`). `BlocksAvulsion` дивиться лише на бойові режими (`Igor.Kop_BattleGuns`),
  бо кожен клієнт рахує обвал сам, і результат не може залежати від того, чи тримає гравець зброю.

## Якщо щось не працює

Лог Unity Web Player лежить у `%LOCALAPPDATA%\Temp\UnityWebPlayer\log\`. Помилки гри (Exception)
видно саме там.
