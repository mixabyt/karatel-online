# Копатель Онлайн 2014: лаунчер і приватний сервер

Оригінальний клієнт 2014 року (`Digger2014.unity3d`, Unity 4.5) з Wayback Machine, трохи пропатчений,
щоб працював з нашим сервером. Firefox 51 і Unity Web Player вшиті в лаунчер.

## Як грати
1. Запусти сервер (на цьому ПК або на VPS):
   ```bash
   python server/server.py
   ```
   Потрібен тільки Python 3.10+, без додаткових пакетів.
2. Запусти `KopatelOnline2014.exe`, введи адресу сервера (`127.0.0.1:8080` для свого ПК, `IP:8080` для чужого) і натисни «Грати».
3. У грі натисни «Регистрация» (будь-який логін на кшталт `ім'я@local` і пароль), потім «Войти».
   Повідомлення «на почту выслано письмо» — це оригінальний текст гри, підтверджувати нічого не треба.

Гра відкривається на весь екран як окрема програма: вкладок, меню, гарячих клавіш і сторінок
Firefox немає, а посилання з гри відкриваються в системному браузері. **F11** або **F12** перемикає
між повним екраном і вікном. **Esc** відкриває й закриває меню гри, і мишка лишається в грі.
Лаунчер працює у фоні, доки відкрита гра: він підміняє Esc на `` ` ``, бо Unity Web Player на Esc
завжди відпускає мишку. Виходити з гри через меню або Alt+F4.

Друзі заходять у твою карту через «Список серверов». Будувати й копати в чужій карті можна лише
тоді, коли власник карти видасть права (так влаштовано в самій грі: «Изменять карту нельзя…»).

Монети й кристали видаються безкоштовно (20000 / 2000), магазин працює, слотів для карт 5.
Карти зберігаються на сервері (`server/data/worlds`), акаунти й профілі — у `server/data/db.json`.

## Порти
| Порт | Що | |
|---|---|---|
| 8080/TCP | сторінка, клієнт, PHP-скрипти гри | `--http-port` |
| 843/TCP | socket policy для Unity Web Player | обов'язково саме 843 |
| 5055/TCP | Photon master (лобі, пошук кімнат) | клієнт завжди йде на 5055 |
| 5056/TCP | Photon game server (кімнати) | `--game-port` |

На VPS усі чотири треба відкрити у фаєрволі. Якщо сервер стоїть за NAT (зовнішній IP не на
інтерфейсі), додай `--public-host <зовнішній IP>`: цю адресу клієнти отримують для game server.
Приклад systemd-юніта: `deploy/kopatel2014.service`.

## Як це влаштовано
- `docs/protocol.md` — що клієнт шле і що чекає (HTTP і Photon), і список патчів.
- `server/` — сервер: `kopatel/web.py` (сторінка + емуляція PHP), `kopatel/photon/` (Photon по TCP:
  Protocol16, обмін ключами, LoadBalancing master/game), `kopatel/db.py` (дані).
  `python -I server/tests/smoke_test.py` перевіряє запущений сервер так, як це робить клієнт.
- `tools/build_client.ps1` — збирає `server/www/Digger2014.unity3d`: качає оригінал з архіву,
  розпаковує (`tools/unityweb.py`), патчить `Assembly-CSharp.dll` (`tools/patcher`, Mono.Cecil) і пакує назад.
  Потрібні .NET SDK (для патчера) та Python.
- `launcher/build.ps1` — збирає `KopatelOnline2014.exe` (штатний `csc` .NET Framework 4);
  `payload.zip` (Firefox 51 + Web Player) береться з `KopatelOnline2012.exe`.
- `work/` — проміжні файли збірки (розпакований клієнт, декомпільований код). Можна видалити:
  `build_client.ps1` створить їх знову.

## Чого немає
- Паки `content/*.unity3d` (додаткові звуки й текстури) не збереглися в архіві: гра працює на вбудованих.
- Оплати, відновлення пароля і щоденного бонусу немає.
- Голосовий чат (Unity Network) не перевірявся.
