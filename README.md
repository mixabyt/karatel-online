# Копатель Онлайн 2012: відновлення гри

Мета проєкту: знову грати в браузерну версію «Копатель Онлайн» 2012 року (Unity 3.5, Unity Web Player)
на власному локальному сервері, без оригінальної інфраструктури, якої вже не існує.

## Історія і що з'ясувалося

- **Гра.** «Копатель Онлайн» (Digger Online) — російська пісочниця 2011 року від Максима Дмитрієва.
  Спершу вона виходила як застосунок ВКонтакте на Unity Web Player, у 2015-му з'явилася в Steam.
- **Клієнт.** Фанатський сайт kopatel-online.ru викладає «відновлені» клієнти 2012 та 2014 років.
  Обидва в такому вигляді не працюють:
  - **Мультиплеєр (Photon Cloud):** AppID оригінальної гри видалено, хмара відповідає
    `ApplicationNotFound`.
  - **Клієнт 2012 року:** фанати вирізали з нього (замінили на `nop`/`ret`) підключення до сервера,
    створення кімнат, появу гравця, налаштування камери, синхронізацію руху та завантаження звуків.
    Ще одна їхня правка зробила `WorldGameObject.Update` некоректним IL, і Unity його відкидав.
  - **PHP API фан-сайту:** частково не працює, на слоти карт відповідає `SERVER_ERROR`.
  - **Звуки:** пакета `Sounds3.unity3d` більше ніде немає.
- **Рішення.** Власний сервер (HTTP API та емулятор Photon) і патч клієнта 2012 року. Вирізаний
  код відтворено за клієнтом 2014 року, де він зберігся.

## Як запустити

Потрібні Windows, Python 3.10+, Firefox 51 (32-біт, з вимкненим автооновленням) і Unity Web Player.

1. Запустіть `kop\server\run_server.bat` і дозвольте Python доступ у брандмауері.
2. Відкрийте у Firefox 51 сторінку `http://127.0.0.1:8080/`.
3. Зареєструйтеся (пошта й пароль зберігаються лише локально), виберіть нік, створіть карту в «Мои карты».

Порти: 8080 (сайт і API), 4530 і 4531 (Photon), 843 (socket policy для Unity Web Player).
Як грати з друзями в мережі чи через інтернет, описано в [kop/server/README.md](kop/server/README.md).

### Лаунчер одним exe

`kop\launcher\dist\KopatelOnline2012.exe` (≈70 МБ) містить портативний Firefox 51 і Unity Web Player,
тож гравцеві нічого не треба встановлювати. Лаунчер питає адресу сервера (`IP`, `IP:порт` або повну
URL; без порту береться 8080), запам'ятовує її й відкриває сторінку гри у вікні Firefox без панелей.
Firefox розпаковується в `%LOCALAPPDATA%\KopatelOnline2012` з окремим профілем і не чіпає інші браузери.
Unity Web Player ставиться туди ж, куди його кладе власний інсталятор (`LocalLow\Unity\WebPlayer`),
лише якщо його там ще немає. Зібрати exe з вашого Firefox 51 і Web Player:

```bash
python -I kop/launcher/build_launcher.py --server <ваш IP>:8080
```

`--server` задає адресу, яку лаунчер запропонує за першого запуску.

Повний екран у лаунчері (кнопка «На весь экран» або F12 у грі) — це повноекранний режим самого
Firefox (як F11), і Esc, клавіша ігрового меню, з нього не виходить. Вийти можна кнопкою «Обычный
режим» у шапці сторінки або через F12.
Вмикає його `mozilla.cfg` (Firefox AutoConfig, кладеться в портативний Firefox), на запит сторінки.
У звичайному браузері лишається повний екран сторінки або Unity, і з нього Esc, як і раніше, виходить.

## Стан

| Що | Стан |
|---|---|
| Вхід, профіль, нік, магазин, слоти, збереження й завантаження карт | працює, перевірено в грі |
| Руйнування й встановлення блоків, ігрове меню | працює, перевірено в грі |
| Публікація карт, топи, пошук, коментарі, оцінки | працює на сервері (тест), у грі не перевірялось |
| Звуки (89 кліпів з новішої збірки гри) | зібрано, у грі ще не перевірено |
| Підключення до Photon (вимкнено обмін ключами шифрування) | зібрано, у грі ще не перевірено |
| Гра з друзями (кімнати, передача карти, рух інших гравців) | відновлено в клієнті, удвох не перевірялось |
| Звук вибуху динаміту й авіабомби (класичний звук TNT із Minecraft) | зібрано, у грі ще не перевірено |
| Зброя на картах для будування (клавіша G) | зібрано, у грі ще не перевірено |
| Голосовий чат (P — говорити, O — увімкнути або вимкнути передачу) | працює: звук від гравця доходить через сервер, повернення ботом перевірено |

Якщо сервер недоступний, клієнт сам переходить в офлайн-режим PUN, і грати можна поодинці.

## Структура

```
kop/
  server/                 локальний сервер — те, що запускається
    run_server.bat/.py    запуск (HTTP + Photon)
    kopserver/            protocol16.py, photon.py (емулятор LoadBalancing), web.py (PHP API), db.py
    www/                  сторінка гри, пропатчений Digger2012.unity3d, sounds/*.wav
    data/                 keys.json (пара до клієнта), db.json і worlds/ (акаунти та карти)
    patcher/              патчер клієнта на C# (Mono.Cecil)
      Fixes/KopFix.cs     відтворений код, вбудовується в класи гри 2012 року
      ildump/             утиліти для розбору IL (дамп, перевірка стеку, пошук фанатських заглушок)
    tools/                build_client.py, unityweb.py (пакування .unity3d), extract_sounds.py
    tests/smoke_test.py   наскрізний тест сервера
    README.md             детальна інструкція до сервера
  launcher/               лаунчер одним exe: Launcher.cs, user.js, userChrome.css, mozilla.cfg і
                          autoconfig.js (налаштування Firefox),
                          build_launcher.py; результат у dist/
  src2012/, src2014/      декомпільований C#-код клієнтів (ILSpy), для довідки
  dl/                     оригінальні клієнти з фан-сайту та їх розпакований вміст
  build/                  проміжні результати збирання, можна видалити
  tools/                  ранні дослідницькі скрипти (розпакування, зонд Photon Cloud)
```

## Перезбирання клієнта

Потрібен .NET SDK (9+) і встановлений Unity Web Player (з нього беруться бібліотеки для компіляції `KopFix.cs`):

```bash
python -I kop/server/tools/build_client.py kop/dl/client2012.unity3d
```

Команда пропатчує клієнт і перезапише `www/Digger2012.unity3d`. RSA-ключ береться з наявного
`data/keys.json`, тому запущений сервер перезапускати не треба: гравці отримають новий клієнт
при наступному запуску. Новий ключ генерується, лише якщо `keys.json` немає, і тоді сервер треба
перезапустити. Звуки перевитягуються з `diggerworld.zip`
(фанатський лаунчер на Яндекс.Диску) командою `tools/extract_sounds.py`, для неї потрібна бібліотека UnityPy.

## Що змінює патчер у клієнті 2012 року

- Усі адреси kopatel-online.ru беруться з того сервера, звідки завантажено гру.
- Photon підключається по TCP до порту 4530 того самого хоста, обмін ключами шифрування вимкнено.
- Відновлено вирізане фанатами: підключення з меню, створення кімнати й вхід до неї, поява гравця
  через `PhotonNetwork.Instantiate`, камеру, межі карти, інтерполяцію руху, завантаження звуків,
  22 перевірки `photonView.isMine`.
- Виправлено некоректний `WorldGameObject.Update`.
- Динаміт і авіабомба при вибуху грають `sounds/Explode_1..4.wav`: класичний звук TNT із Minecraft,
  який був там від бети до 1.20 (`random/explode1..4.ogg`, взято з індексу ассетів 1.20 і
  переведено у WAV через ffmpeg).
- На картах для будування клавіша G дає зброю, як у бою: вибір зброї з купленої в магазині, 1–4,
  R, шкода гравцям, смерть і відродження. Набої поповнюються після кожного G. Ще раз G повертає
  лопату й збережену камеру. Блоки кулями й гранатами ламають лише будівельники карти. «Висячі»
  блоки, як і раніше, обвалюються тільки в бойових режимах.
- Для покупок за монети використовується новий RSA-ключ.
- Відтворений код містить лише IL, сумісний зі старим верифікатором Unity Web Player.
  Патчер сам зупиняє збирання на конструкціях, які той не прийме: `constrained.`-виклики та
  доступ до приватних членів інших класів.

## Діагностика

- Лог гри: `%LOCALAPPDATA%\Temp\UnityWebPlayer\log\`. Рядки `Kop sounds:` показують, скільки кліпів
  завантажилося, які не вдалися, а також кількість `AudioListener` і гучність.
- Лог сервера виводиться в консоль `run_server.bat`. Там видно підключення до Photon,
  входи в кімнати й усі запити до API.
